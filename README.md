# EVORQIS website (Next.js 14 + Tailwind + Framer Motion)

    npm install
    npm run dev      # http://localhost:3000
    npm run build && npm start

Deploy free: push to GitHub, import the repo on vercel.com (no settings needed).

Edit content in `lib/content.ts` (email, services, stats, pricing, FAQ, testimonials).
Newsletter endpoint: `app/api/subscribe/route.ts` (connect your email provider there).
